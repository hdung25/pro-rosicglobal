# Hồng Tâm Rosic Global catalogue demo

## Scope and safeguards

- Keep the public root in maintenance mode while the new catalogue is reviewed.
- Publish the catalogue through the `?demo=catalog` preview route. The root route remains the customer-facing maintenance page.
- Use Vdelta only as a layout reference: a category-discovery layer followed by product-level detail and a contact path. No Vdelta wording, images, logos or product assets are used.
- Use Visimex public product pages only as a research reference for which commercial fields buyers commonly request. Do not claim Visimex certifications, facilities, products or measurements as Hồng Tâm Rosic commitments.
- Label all displayed values as reference checkpoints. Final product specifications must be confirmed with an approved sample, contract and batch COA.

## Information architecture

1. Header and one of two logo layouts
2. Export catalogue hero with an original logo-free agricultural image
3. Single continuously moving rail for trade-readiness principles
4. Eight-category discovery grid
5. Clickable large-image product detail dialog
6. Specifications panel with category selector
7. Header-layout comparison
8. Contact, valid social links and centered copyright

## Category checklist

- Hạt điều nhân: grade, lot COA, safety checks, packing
- Quế cassia: moisture, foreign matter, dimensions, volatile oil, packing
- Hạt tiêu: bulk density, screen, moisture, foreign matter, broken grains
- Hoa hồi: harvest form, moisture, foreign matter, flake size, broken percentage
- Cà phê hạt: screen retention, moisture, foreign matter, black/broken beans, packing
- Cơm dừa sấy: fat, moisture, FFA, SO₂ contract limit, microbiology
- Trái cây sấy: formula, moisture or aw, microbiology, shelf life, pack
- Điều thành phẩm: formula, allergens, microbiology, net weight, artwork
